## Design Context

### Users
Owen monitors real Paseo coding agents across local and registered remote hosts, projects, and worktrees.

### Brand Personality
Calm, trustworthy, spatial. Inherited from the existing Paseo Command PRODUCT.md and DESIGN.md in /Users/example/development/paseo-command, not a newly approved visual direction.

### Aesthetic Direction
Preserve the existing React work surface. Four worlds interpret one host-qualified model. Galaxy: dark space and warm brass. Lake: meadow, timber and cream. Atlas: overhead geographic cells. Diorama: dimensional enamel buildings and robots. The active rendering study in `rendering/` uses open-source Phaser 4.2.1, generated painted sprite atlases, parchment hex terrain and blue water. The five user-supplied top-down illustrations in `design/references/atlas-01.webp` through `atlas-05.webp` are the visual authority. The earlier AE primitive renderer remains a separate local prototype.

### Design Principles
- Real daemon state is authoritative.
- Conversations and composer remain primary.
- Distinguish running, needs answer, unread completion, idle, failure and offline states.
- Preserve keyboard access, drafts, host identity and reduced motion.
- Test mutations against fake daemons only.
