## Design Context

### Users
Developers monitor real Paseo coding agents across local and registered remote hosts, projects, and worktrees.

### Brand Personality
Calm, trustworthy, spatial. Preserve the established Paseo Command interface.

### Aesthetic Direction
Preserve the existing React work surface and system light/dark appearance. The Atlas is drawn by SpriteKit in the macOS app: overhead geographic hex cells, generated painted sprite atlases, parchment terrain and blue water. Five user-supplied top-down illustrations informed its style; those private references are excluded from the repository. Do not restore retired renderers or add worlds.

### Design Principles
- Real daemon state is authoritative.
- Conversations and composer remain primary.
- Distinguish running, needs answer, unread completion, idle, failure and offline states.
- Preserve keyboard access, drafts, host identity and reduced motion.
- Test mutations against fake daemons only.
