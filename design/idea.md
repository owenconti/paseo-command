# Paseo Command

A game/app to manage Paseo workspaces and agents via the Paseo daemon: paseo.sh. Paseo Command is a visual command centre for managing your AI coding agents across projects, workspaces, and local or remote machines. It brings conversations and agent controls into one place, with a strong focus on surfacing agents that have finished, need approval, or are waiting for an answer. Its distinctive feature is a game-like world that represents your development work spatially. You can switch between Galaxy, Lake Country, Atlas, and Diorama, where hosts, projects, workspaces, and agents appear as planets, villages, buildings, satellites, or robots. These worlds reflect real agent state and help you find the conversation that needs your attention. You can dispatch agents, read their conversations, send prompts and attachments, handle approvals, queue work, and archive completed work without leaving the app. It runs as a standalone web app or a macOS desktop app combining world rendering with a React interface. Paseo supplies the underlying agent infrastructure; broader GitHub, Linear, and alert integration is part of the longer-term vision. Build this version with Phaser AE rather than Unity, keeping real daemon integration and an attention-first command centre as the priority.
